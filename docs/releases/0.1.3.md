# Home Panel Configuration 0.1.3

- Add, rename, move and remove read-only `binary_sensor.*` cards on room
  pages. For example, show a plug fault, contact or motion sensor.
- The administrator catalog for this card lists only binary sensors. The
  editor offers it only when the panel advertises both `widget.status` and
  the `status` widget type.
- The existing Check, Send and Apply steps remain separate. Adding a card
  does not change the entity, create an automation or trigger an alert.

## Install

Requires Home Assistant 2026.11.0 or newer. In Marketplace, select 0.1.3.
Use `home_panel.zip` for Marketplace and `home-panel-ha.zip` for manual
installation. Both include Core 0.1.3 at the exact commit in
`core-source.json`. Restart Home Assistant after upgrading the integration.

No firmware update is required on a panel that already advertises status
cards. Older panels can still use compatible features; the new option will
not appear. The standard ESPHome integration remains responsible for live
states.
