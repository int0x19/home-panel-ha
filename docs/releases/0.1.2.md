# Home Panel Configuration 0.1.2

- Add a numeric-sensor and group draft editor for firmware that advertises
  the readings profile. The entity picker uses allowlisted unit/class defaults
  and preserves unknown settings.
- Allow HA administrators to Check and Send a draft to the candidate slot on
  compatible flash-backed firmware. The original snapshot and exact readback
  protect against stale drafts. Send does not activate the configuration.
- Add explicit Discard and backup-to-candidate recovery. Neither changes the
  active configuration. Applying the staged candidate is a separate confirmed
  action. Only verified post-restart readback is shown as applied.

## Install

Requires Home Assistant 2026.11.0 or newer. Select the **0.1.2** release in
Marketplace. Use `home_panel.zip` for Marketplace or `home-panel-ha.zip` for
manual installation into the HA configuration directory. Both bundle the
same core 0.1.2, pinned in `core-source.json`. Keep the existing ESPHome
integration for states and device control. No firmware is included.

Send requires healthy flash storage and `write-base.v1`; Apply also requires
enabled boot trials. On older firmware those controls stay unavailable.
Successful Apply makes the former active configuration the backup. Export
both original records before evaluating it. There is no automatic Apply,
new household action transport, or requirement for an SD card.

## Verification

Local acceptance: 262 HA tests with Chromium and offline bundles, 80
installed-core tests and 12 Linux checks against the production flash
HTTP/NVS code. The panel OTA confirmed `write-base.v1`, exact preservation
of active/backup JSON and reconnection of readings. The complete workflow
through installed HA and the physical panel remains to be verified.
