# Home Panel Configuration 0.1.2

Development candidate, not yet published.

- Bundle core 0.1.2 with shared numeric-sensor/group draft editing.
- Add sensor entity/name/unit/class, named/unnamed groups and stable moves.
- Reuse mixed-row/no-scroll guards, HA checkpoints and independent validation.
- Add a scoped HA sensor picker with only allowlisted unit/class defaults.
- Preserve opaque settings, exact originals and negotiated capability gates.
- Recognize the explicit flash `esp32-readings-preview` capability target and
  show its negotiated sensor/status inventory without granting write authority.

The deployed action-only configuration profile still disables Add sensor.
This does not add managed Send/Apply, update firmware, send household commands
or certify runtime readings on the panel. Published 0.1.1 remains the
installation release until a new release is separately verified and published.

Acceptance: 213 HA/browser tests, 50 installed-core tests and 70 scoped native
HTTP/NVS/LVGL checks (one optional skip). Browser-exported JSON survives the
fake-NVS/API round-trip and existing Linux rendering without overflow/commands.
The source lock is recorded in `core-source.json`; no firmware is included.
HA/core 0.1.1 reject the new readings target. Verify the new companion before
deploying that firmware profile; this is not a downgrade-transparent change.
