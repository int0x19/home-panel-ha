# Home Panel Configuration 0.1.0

Initial companion integration release for Home Assistant 2026.11.0 or newer.

## Installation

Install through Marketplace using the published **0.1.0** release, not `main`.
The required asset is `home_panel.zip`; the shared core and licenses are bundled.
No separate pip, PyPI package or firmware repository is required on the HA host.
For manual installation, extract `home-panel-ha.zip` into the HA configuration
directory instead. Restart Home Assistant when requested.

Add **Home Panel Configuration** through Devices & Services. The panel must run
compatible firmware exposing the configuration HTTP identity/capabilities API.
Enter its local address and configuration key, not a Home Assistant access token.
Keep the standard ESPHome integration for live device states and actions.

## Included

- Administrator-only panel metadata, exact configuration export/import and
  validation through the negotiated device contract.
- HA-side room/action draft editing, entity selection, change summaries,
  bounded saved checkpoints and unsaved-navigation protection.
- English/Russian interface and local integration icon.

## Limits

This integration does not flash ESP32 or automatically migrate a YAML panel.
Saving a draft in HA does not save/apply it on ESP32. Managed device writes and
additional runtime widget families remain capability-gated roadmap work.
There are no household service calls in this release's read/check client.

The release fixes initial CI browser dependency setup and declares the HTTP
component dependency checked by hassfest. Firmware and household devices are
not modified by this packaging release.
