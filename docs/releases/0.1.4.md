# Home Panel Configuration 0.1.4

- Background Home Assistant state updates no longer repaint the editor or
  interrupt scrolling and typing. Entity suggestions still use current states.
- All frontend assets share a content-derived URL prefix, so an upgraded
  installation does not mix cached editor modules, CSS or shared Core assets
  with the new files.

Core remains pinned to 0.1.3. No device firmware, configuration migration
or pairing change is needed. Restart Home Assistant after installation and
reopen Home Panel.

Local verification: 266 HA tests (including Chromium and both ZIP layouts).
A separate Firefox ESR test with 0.1.2 assets in cache loaded the new module
graph, opened the binary sensor form and preserved scroll, focus and text
across state updates. The working HA installation has not been upgraded
as part of this check.
