# Home Panel Configuration 0.1.1

Fix pairing with the deployed internal-flash firmware. Version 0.1.0 incorrectly
rejected `loaded_source: flash-confirmed` as incompatible firmware even when
the factory identity and `capabilities.v1` were valid.

- Bundle core 0.1.1 with explicit `flash-nvs` / `flash-maintenance.v1` support.
- Accept confirmed, previous and trial flash sources without requiring SD.
- Gate configuration export/import on `storage_ready`, not `sd_ready`.
- Forward the required flash generation guard for export/validate and reject
  storage-generation changes during a read/check transaction.
- Show configuration storage and translated flash sources in the HA editor.
- Retain legacy SD compatibility and all identity/session/digest/limit guards.

Update the integration in Marketplace, restart Home Assistant when requested,
then retry adding the panel with the same address and configuration API key.
The password field is deliberately cleared after failed attempts. A firmware
build/OTA, new panel identity or SD card is not needed for this fix.

Managed device writes, applying drafts and household actions remain disabled.

Read-only status/capabilities, exact active JSON export and the panel's own
validate-only job were checked against a running ESP32 using internal flash.
No firmware build/OTA, persistent file change or household action was involved.
